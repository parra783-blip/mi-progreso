# Mi Progreso

PWA gratuita para iPhone, sin servidor y sin cuentas.

## Publicar gratis en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. Ve a Settings → Pages.
4. En Source selecciona “Deploy from a branch”.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda y abre la URL que GitHub genere.

## Instalar en iPhone

1. Abre la URL en Safari.
2. Pulsa Compartir.
3. Elige “Añadir a pantalla de inicio”.
4. Activa “Abrir como app” si aparece.
5. Pulsa Añadir.

## Privacidad

Todos los registros se almacenan en el navegador del dispositivo mediante localStorage.
Haz respaldos periódicos desde Más → Exportar respaldo.
